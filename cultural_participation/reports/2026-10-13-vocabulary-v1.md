# 微博跨领域文化参与词表：构建与筛选阶段报告

日期：2026-10-13

版本：`strict-v1-2026-10-13`

研究对象：2020年微博热搜辅助生成的领域关键词

阶段状态：词表筛选与合并完成；尚未报告原微博的领域命中、性别差异或行为分析结果。

## 1. 本阶段的研究目的与产物

本研究拟描述不同性别用户在不同信息领域中的文化参与模式，后续使用原始微博中的转发行为、转发时间和表达行为开展跨领域比较。热搜在此作为发现关键词的来源，最终分析样本不限定为直接参与热搜词条的微博。领域参与差异是否与性别关联、文化声望或地位评价相联系，需要另行测量；本阶段词表没有提供机制、因果或“不平等”成立的证据。

最终形成 **3,972个不重复词条**，覆盖五个领域。其中2,971词来自双模型领域及独立适用性一致的部分，1,001词来自本轮模型辅助裁决。134词保留多个领域，因此共有4,107个“词—领域”对应关系。词表、统计和生成代码均随仓库版本管理。

- [正式词表 JSON](../vocabularies/strict_v1/vocabulary.json)：供现有 Vocabulary 接口读取。
- [完整词表 CSV](../vocabularies/strict_v1/vocabulary.csv)：供阅读、筛选和核查。
- [机器可读统计](../vocabularies/strict_v1/summary.json)：数量、频率分组、各域前10词及输入哈希。

## 2. 候选来源、模型分类与筛选流程

本轮对应服务器上的`full_2020_v2_17086`候选与分类任务，共36,876词。用户确认输入覆盖全部日期；本地未在本阶段重新审核逐日覆盖。模型运行记录均指向这次任务。仓库中另有早期35,291词的候选摘要，不能与本轮分母混用。

分类经OpenRouter分别使用`deepseek/deepseek-v4.1-flash`和`qwen/qwen3.8-flash`，每次一个词，关闭reasoning。候选任务包含词形、不同原标题数量及至多三条原标题例句。例句按标题排序选取，不是全部语境的随机样本。两个模型分别判断目标领域和词条独立适用性，保留“都不是”和无法判断选项。

## 3. 最终纳入口径与人物处理

最终版只保留standalone。已有裁决时采用裁决结果；未裁决时，要求两个模型的目标领域集合完全相同，并且双方都为standalone。context_required、exclude、none、uncertain以及失败请求均不进入本版。领域集合以集合比较，不受标签排列顺序影响。

身份明确的完整人名或稳定艺名允许按人物主要活动领域保留，不额外要求微博正文谈论其职业活动。例如政治人物、运动员、演艺人物和科学家可构成相应领域的关联对象。含义不清的简称、姓名切片和实际同名未消歧项暂缓。其测量含义是“围绕领域人物的参与”；不能把每次提及都解释为讨论该领域的实质议题。

本轮明确标记了713个人物词（term_type=person、participation_basis=person_association）。这是已识别并标记的数量，**不是整个词表的人物总数**：双模型一致部分尚未统一补充词类，拜登、易烊千玺等也在其中。未标记的词不能视为“非人物”，更不能直接据此构建完整的纯话题/纯人物对照。

approved=true表示该词通过用户确认的纳入规则，方便现有接口读取；不表示逐词人工验证。词表保留selection_source、scope_id、selection_reason和distinct_title_count以追溯来源。

## 6. 对后续论文与分析的含义

**词表的领域覆盖不均衡。** 文艺娱乐有1,579词，科技有311词，相差约5.1倍。词条数量受人物与作品命名密度、热搜议程、分词和筛选规则影响；这不等于参与文艺的人更多，也不等于科技领域不重要。直接比较命中量时，应关注词表覆盖和识别机会的差异。

**领域并非互斥。** 134个多领域词形成跨域关联，例如华为、SpaceX涉及商业与科技，票房涉及文艺与商业。本版保留这些标签，现有匹配会给命中的词赋予全部对应领域。因此后续应将领域参与作为可重叠指标，并另做仅单领域词的敏感性分析，不能把这些命中解释为用户主动跨越领域边界。

**2020年的议程结构可见于高频词。** 科技高频词包括钟南山、李兰娟、临床试验，政治高频词包括特朗普、世卫、卫健委；这是该年候选材料的描述。人物口径使科学家相关参与可以进入科技，但医疗健康整体仍不属于五领域体系。文艺列则包含文化形式和大量演艺人物，体育列兼有传统体育和电竞组织。这些组成差异应成为结果解释的背景。

**大量词仅出现于少数原标题。** 其中只出现在1个标题的词有1,553个（39.1%），2—4个标题有1,247个，5—9个有536个，10—49个有553个，至少50个有83个。低频不等于错误，可能是完整人物或作品名；高频也不等于准确。删词重采样可检查结果对词表组成的敏感程度，但不能证明热搜来源在总体文化实践上的代表性。

**本版按已有标记严格筛选，尚未统一重审一致部分。** 双模型都判独立可用的企业、机构或通用名词被保留，而裁决部分采用了更具体的边界判断；仍可能存在来源之间的宽严差异或共同错误。两个模型一致不是准确率。不能声称本版已排除全部实际歧义。

后续优先在原微博命中样本中按领域和词表来源分层抽查，估计误匹配并检视漏检；补齐全词表的人物、组织、作品、话题等类型后，比较包含/排除人物的结果。再进行跨领域性别参与比较、只用单领域词、不同来源词以及删词重采样等敏感性分析。英文短缩写、嵌套词和子串边界需特别检查；当前Vocabulary接口是全重叠字面匹配，不自动完成实体消歧。

文化性别关联、声望与地位的embedding或调查测量应作为后续独立证据层，与行为参与数据区分。本阶段不根据词表大小或领域性别差异推断devaluation，也不声称识别其机制。

## 7. 文件、复现与版本边界

本版保留CSV与JSON快照，克隆仓库后无需原模型响应即可使用。完整模型响应、逐词裁决证据和原始数据保存在本地/服务器数据目录，不将数百MB响应一并提交。summary.json记录两个合并输入的SHA-256；复算需要取得这两个未随Git保存的输入文件。

```bash
python -m cultural_participation.finalize_vocabulary \
  --paired gender_norms/newspaper_data/cultural_participation/classification_audit_20261013/paired_terms.csv \
  --reviewed gender_norms/newspaper_data/cultural_participation/adjudication_v1/final_selected_adjudications.jsonl \
  --output-dir cultural_participation/vocabularies/strict_v1 \
  --version strict-v1-2026-10-13
```

本次验证覆盖：裁决优先且不会恢复被排除词、上下文词和领域分歧词不进入一致集合、标签顺序无关、去重计数、领域集合合法，以及正式JSON可被现有Vocabulary接口加载。尚未运行原微博全量行为分析。修改筛选规则或词条后应创建新版本，不将新结果与本版混报。
